# 🩺 Diabetic Retinopathy Detection System

An AI-powered application for **automatic detection and severity classification of Diabetic Retinopathy (DR)** from retinal fundus images.  
The system helps in **early diagnosis, fast screening, and accurate severity assessment**, supporting better clinical decision-making.

---

## 📌 Project Overview

Diabetic Retinopathy is one of the leading causes of vision loss among diabetic patients. Manual screening is time‑consuming and requires expert ophthalmologists.  
This project uses **Deep Learning (Convolutional Neural Networks – CNNs)** to analyze retinal images and classify the severity of DR automatically.

The system is designed to be **simple, fast, and user‑friendly**, making it suitable for hospitals, clinics, and large-scale screening programs.

---

## 🎯 Key Features

- 📷 Upload retinal fundus images (JPG, JPEG, PNG)
- 🤖 CNN-based automated image analysis
- 📊 Severity classification into **four DR levels**
- 🖥️ Clean and intuitive web interface using Streamlit
- ⚡ Fast predictions using trained deep learning models
- 👩‍⚕️ Easy-to-understand results for non-technical users

---

## 🧠 DR Severity Levels

- **No DR** – Healthy retina  
- **Mild DR** – Early-stage damage  
- **Moderate DR** – Noticeable retinal damage  
- **Severe DR** – High risk of vision loss
